# Roadmap

## Phase 1 — Canonical model (this release)
- [x] Host / Parasite / Association schema
- [x] MSB:Para adapter
- [x] KSB host-part adapter
- [x] Evidence types
- [x] Host Mode / Parasite Mode

- [ ] Query REST API

- [ ] FastAPI backend
