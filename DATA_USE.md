# Data Use and Attribution

The Kansas Host–Parasite Atlas is a derived discovery and visualization product built from natural history collection records.

## Authoritative records

Arctos and the contributing collections remain the authoritative sources for specimen metadata. Users should follow host and parasite GUIDs back to the source records before analyses requiring current taxonomy, complete locality information, georeferencing uncertainty, restrictions, or collection-specific metadata.

## Attribution

Users should cite the archived atlas release when the atlas software or derived dataset contributes materially to a study. Users should also cite or acknowledge the contributing collections and underlying specimen records according to the requirements and norms applicable to those data.

## Licensing distinction

The repository's MIT License applies to the software code authored for this project. It does not grant new rights over specimen data originating from Arctos or contributing institutions. Source-data terms, restrictions, and attribution requirements remain applicable.

## Responsible interpretation

Museum specimen records are not necessarily produced by standardized sampling. Atlas record counts should not be interpreted as biological abundance, prevalence, intensity, or absence without an analysis and sampling design that supports those inferences.
