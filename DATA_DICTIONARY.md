# Data Dictionary

This document describes fields in the CSV generated by **Download Filtered Data**. Each row represents one host–parasite association that satisfies the active atlas filters.

| Field | Definition | Source / interpretation |
|---|---|---|
| `host_guid` | Persistent GUID for the host specimen record | Related host record identified through the cataloged `parasite of` relationship |
| `host_taxon` | Host taxon label displayed by the atlas | Development dataset: derived from `verbatim host ID`; production provenance should be documented |
| `host_collection` | Collection prefix associated with the host GUID | Derived from the host GUID |
| `host_group` | Broad host group | Inferred from collection/GUID conventions used by the processing script |
| `latitude` | Latitude used to map the host point | Development dataset: inferred from linked parasite coordinates; see `METHODS.md` |
| `longitude` | Longitude used to map the host point | Development dataset: inferred from linked parasite coordinates; see `METHODS.md` |
| `parasite_guid` | Persistent GUID for the parasite specimen record | Source parasite record |
| `parasite_name` | Parasite scientific name | Source parasite record |
| `parasite_kingdom` | Parasite kingdom | Source taxonomy |
| `parasite_phylum` | Parasite phylum | Source taxonomy |
| `parasite_class` | Parasite class | Source taxonomy |
| `parasite_order` | Parasite order | Source taxonomy |
| `parasite_family` | Parasite family | Source taxonomy |
| `parasite_genus` | Parasite genus | Source taxonomy |
| `parasite_species` | Parasite species | Source taxonomy |
| `collection_year` | Explicit four-digit year extracted from the record date | Blank when no explicit four-digit year was available |
| `location_in_host` | Anatomical or other location of parasite in/on host, when recorded | Parsed from specimen attributes |
| `parasite_life_stage` | Parasite life stage, when recorded | Parsed from specimen attributes |
| `parasite_sex` | Parasite sex, when recorded | Parsed from specimen attributes |
| `individual_count` | Individual count associated with the parasite record, when recorded | Parsed from specimen attributes |

## Important interpretation

The exported table is relational specimen data, not a standardized epidemiological sampling table. Multiple parasite records may be linked to one host, and collection effort is not necessarily equal among hosts, places, dates, or taxa. Therefore, row counts should not automatically be interpreted as prevalence, abundance, intensity, or sampling effort.
