# Host–Parasite Relational Atlas — Practice

This is a separate practice project built from an Arctos parasite export containing independently cataloged parasite records and explicit `parasite of` links to host GUIDs.

## Dataset

- 53,870 source parasite records
- 51,790 parsed parasite-to-host relationships
- 40,733 mapped parasite-to-host relationships
- 30,849 unique host GUIDs
- 24,379 host GUIDs with an inferred map location
- 1,041 parasite identifications
- 1,500 host identifications recovered from parasite attributes

## Practice architecture

### Parasite mode
One point represents one independently cataloged parasite record linked through `parasite of` to a host GUID.

### Host mode
Parasite relationships are collapsed by host GUID. The practice host point uses the coordinates of linked parasite records because a separate host export was not supplied. This is an inference for the prototype, not a replacement for authoritative host coordinates.

## Host metadata

`verbatim host ID` is extracted from `ATTRIBUTEDETAIL` and displayed as the host taxon. The related Arctos host GUID is extracted from `RELATEDCATALOGEDITEMS`.

## Features

- Parasite ↔ host clickable GUID relationships
- Parasite and host map modes
- Dual-handle year slider
- Host group and host collection filters
- Parasite genus and species filters
- Host taxon search
- GUID/taxon search
- Marker clustering
- Street, topographic, satellite, and light basemaps

## Local testing

Because the site loads separate GeoJSON files, serve it over HTTP:

    python3 -m http.server 8000

Then open:

    http://localhost:8000

GitHub Pages will work normally.

## Data files

- `data/parasites.geojson` — mapped parasite-to-host relationships
- `data/hosts.geojson` — host-mode features generated by collapsing parasite relationships by host GUID
- `data/parasite_relationships.csv` — normalized relationship table
- `data/hosts_normalized.csv` — one row per host GUID
- `data/summary.json` — project summary

This project is intentionally separate from the KSB Kansas Host–Parasite Atlas so the future relational architecture can be tested without changing the production site.
